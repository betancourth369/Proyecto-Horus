# ADR 0001 — Stack inicial

- **Estado:** Propuesto (pendiente de confirmación del usuario)
- **Fecha:** 2026-10-21

## Contexto

Horus necesita un backend para una primera demostración. El proyecto ya
contiene un backend generado con Spring Boot.

## Decisión propuesta

Usar Java + Spring Boot + PostgreSQL + Spring Data JPA para el backend.

## Estado real

- El backend existe con esas tecnologías (observado en `pom.xml`).
- El usuario **aún no ha confirmado** el stack como decisión definitiva.

## Alternativas

- Pendiente de analizar.

## Consecuencias

- Pendiente de documentar cuando se confirme la decisión.

## Nota

Este documento se completará cuando la decisión se confirme. Hasta entonces,
el stack debe tratarse como **estado observado**, no como decisión aprobada.
